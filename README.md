![Category](https://img.shields.io/badge/Factory_Simulation-blue?style=flat-square)

## About

Sandustry is an industrial factory-building and automation game set in a sandy desert environment. Players extract resources, build production chains, automate processes, and expand their industrial empire across procedurally generated landscapes. Combining elements of Factorio-style gameplay with a unique desert aesthetic, Sandustry offers deep systems for production optimization and logistic management.

## Common Problems & Limitations

- **Steep Learning Curve** — Complex production chains take time to master
- **Early Access State** — Game may have bugs and incomplete features
- **Performance Demands** — Large factories can stress CPU and RAM
- **No Multiplayer** — Currently single-player only experience
